# Agentic Essay Writer

An AI-powered essay writing application built with:

- LangGraph
- LangChain
- OpenAI
- Tavily Search
- Streamlit

The app can:

- Plan essays
- Research topics from the web
- Generate drafts
- Critique essays
- Revise outputs
- Export essays as PDF

## Features

- Agentic workflow using LangGraph
- AI-powered research and writing
- Topic suggestion categories
- PDF export
- Streamlit UI

## Tech Stack

- Python
- Streamlit
- LangGraph
- LangChain
- OpenAI API
- Tavily API
